# Agent for Excel

面向数据分析与自动化的 Excel VSTO Agent。当前版本已经形成从“理解任务”到“执行、核验、刷新与审计”的闭环。

## 已实现能力

- 多轮 Agent：任务计划、步骤状态、工具结果续跑、防止模型提前结束。
- Excel 基础操作：读取/写入区域、公式、格式、报告级图表、普通透视表。
- 数据分析：数据体检、字段角色识别、异常与重复检查、安全分析视图。
- 联动看板：KPI、趋势、排名、占比、明细透视、原生切片器与下拉兼容联动。
- Power Query：从区域创建清洗查询，支持类型、去空、去重、重命名、选列、加载与刷新；源表保持不变。
- Power Pivot / DAX：查询入模、关系、度量值、模型透视表、模型与透视表刷新。
- 受控 VBA：预览后执行白名单配方，使用一次性令牌；执行前备份，执行后移除临时模块并写入隐藏审计表。
- 多会话与多模型：聊天持久化、新建会话、模型配置和对话框模型切换。
- 功能中心与分层设置：按分析、报告、数据工程和自动化组织能力；模型、安全、工作簿行为、隐私与诊断分区管理。
- 实时选区上下文：输入区持续显示工作簿、工作表、地址和行列规模；支持 `@当前选区`，并在任务执行期间锁定范围，避免点击其他单元格后目标漂移。
- 分级自动化权限：支持“安全自动化 / 每次询问 / 自定义”；新工作表输出和锁定选区内的空白写入可自动执行，覆盖数据、跨范围、模型关系、DAX、刷新和 VBA 始终确认。
- 运行规则：可持久化保护源表、优先新工作表、默认分析范围、聊天记录和 Power Query / Power Pivot / VBA 权限，并在提示词与执行层生效。
- 内置环境自检：在聊天中调用 `agent_self_check`，检查 Excel、工作簿、Power Query、Power Pivot 与 VBA 权限状态。

## 受控 VBA 边界

当前只允许以下配方：

- `refresh_all`：刷新全部连接、查询、模型和透视表。
- `autofit_used_ranges`：自动调整可见工作表已用区域列宽，最大 40。
- `export_active_sheet_pdf`：导出当前活动工作表为 PDF。

执行要求：

1. 工作簿必须先保存。
2. 必须先调用 `vba_preview_safe`，再使用其一次性令牌调用 `vba_execute_safe`。
3. Excel 需在“文件 → 选项 → 信任中心 → 宏设置”中开启“信任对 VBA 工程对象模型的访问”。
4. 不接受任意 VBA 代码注入。

## 构建与验收

- 主工程：Visual Studio 2022/2026 的 MSBuild，.NET Framework VSTO。
- 主工程已通过 `Debug Rebuild`。
- Power Query、Power Pivot、关系、DAX、模型透视和 VBA 工程对象模型均使用隔离 Excel 实例验证。
- `Tests/Stage1Smoke` 可执行完整回归；若 Windows 智能应用控制拦截未签名测试 EXE，应使用签名测试构件或在受控开发环境运行，不建议关闭系统安全功能。

## 本机安装与验收

1. 关闭所有 Excel 窗口。
2. 解压 `dist/AgentForExcel-1.0.2.zip`。
3. 双击解压目录中的 `AgentForExcel.vsto`，按提示安装或更新加载项。
4. 重新打开 Excel，在聊天中输入“运行 Agent 环境自检”。
5. 需要执行受控 VBA 时，再按前述路径开启 VBA 工程对象模型访问，并重新启动 Excel。

当前发布清单使用项目内的临时开发证书，适合本机测试。面向其他用户正式分发前，应替换为受信任的代码签名证书；不要通过关闭 Windows 安全功能规避签名要求。

逐项验证证据与待完成环境项见 `ACCEPTANCE.md`。

## 安全原则

- 写操作经过范围感知的权限策略：低风险白名单可自动执行，其余写操作继续确认。
- 自动写值和公式只允许落在任务锁定选区的空白单元格内，并受单次单元格数量上限约束。
- 排序、分析、图表和看板默认创建新工作表或值快照，不直接重排源数据。
- Power Query 默认保持源区域不变。
- DAX 仅允许度量值表达式，拦截查询和模型修改语句。
- VBA 采用白名单、一次性令牌、执行前副本和审计记录。
